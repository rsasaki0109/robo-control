# Vendored model

`g1_12dof.rne.urdf` is copied unchanged from Robot Native Engine
(`assets/robots/g1_description/g1_12dof.rne.urdf`, commit `8ff1cb4`), which
generates it from unitree_rl_gym's `g1_12dof.urdf`
(`unitreerobotics/unitree_rl_gym@276801e`). BSD-3-Clause, see
`LICENSE.unitree_rl_gym`. Meshes are not needed: only inertias, joints and the
four sole contact spheres per foot are used.
